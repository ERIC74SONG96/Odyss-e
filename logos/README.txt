Logos partenaires — L'Odyssée Express
=====================================

Fichiers utilisés par les flyers HTML :

  odysee-48h.jpg          → Logo officiel (Wallonie)
  brussels-airlines.svg   → Version simplifiée (remplacer par logo officiel si besoin)
  civis-ulb.svg           → Version simplifiée
  ifc-cameroun.svg        → Version simplifiée
  minepded.svg            → Version simplifiée
  fwb.svg                 → Version simplifiée

Pour remplacer par les logos officiels :
  1. Téléchargez les fichiers PNG/SVG sur les sites « presse » / « branding » de chaque partenaire.
  2. Gardez le même nom de fichier OU modifiez le chemin dans les fichiers FLYER *.html.
  3. Rechargez la page et exportez en PDF.
