Site web L'Odyssée Express
==========================

Ouvrir localement :
  Double-cliquez sur index.html
  OU clic droit → Ouvrir avec → Chrome / Edge

Mise en ligne (odyssee-express.org) :
  Uploadez tout le dossier "site" (index.html, styles.css, assets/)

Fichiers :
  index.html   — page d'accueil
  styles.css   — charte orange #f5821f (style Wallonie 48H)
  assets/      — images
